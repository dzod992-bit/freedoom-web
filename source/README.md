# Chocolate Doom + Freedoom в браузере

Готовая игра находится в `dist/`. Для запуска установленный Emscripten не нужен.

Публичная версия: **https://dzod992-bit.github.io/freedoom-web/**.
Работает независимо от компьютера автора. Открывайте в отдельном Chrome или Edge.

```powershell
# Выполните из папки проекта:
python scripts/serve.py
```

Откройте **http://localhost:8000**, дождитесь загрузки и нажмите **«Играть»**.
Кнопка запускает первый уровень Freedoom 2 на средней сложности и запрашивает
полный экран и Pointer Lock. Страница управляет захватом мыши; игровой движок
не отпускает его при открытии меню. После Esc или потери захвата появляется
кнопка «Вернуться в игру», в том числе в полном экране. Нажмите её для возврата.
Если браузер запрещает Pointer Lock, откройте адрес игры отдельно в Chrome или Edge.

Управление: WASD — движение, мышь — поворот, ЛКМ или Ctrl — огонь,
Пробел — двери/кнопки, Shift — бег, 1–7 — оружие, F2 — сохранение,
F3 — загрузка. Меню также доступно через Esc.

## Что внутри

- Chocolate Doom 3.1.1, исходный commit `895f581c5d91497bdda0516612da803fe5843e28`.
- Freedoom 0.13.0, `freedoom2.wad`, последний релиз на момент сборки.
- Emscripten 6.0.12, встроенные SDL2 и SDL2_mixer, OPL для музыки.
- `ASYNCIFY=1`, явный `emscripten_sleep` в таймере игры,
  `ALLOW_MEMORY_GROWTH=1`, 64 MiB начальной памяти.
- SDL2_net отключён (`ENABLE_SDL2_NET=OFF`); транспорт заменён заглушкой upstream.
  Сборка и интерфейс предназначены для одиночной игры.
- WAD упакован через `--preload-file` в `doom.data`.
- `/persist` смонтирован через IDBFS. До запуска игры выполняется `syncfs(true)`.
  После записи настоящего игрового сохранения выполняется `syncfs(false)`.
  Настройки дополнительно записываются каждые 5 секунд и при скрытии страницы.

## Файлы

- `dist/index.html`, `app.js`, `style.css` — готовая страница.
- `dist/doom.js`, `doom.wasm`, `doom.data` — движок и контент.
- `dist/licenses/` — лицензии и авторы.
- `dist/source/` — соответствующие исходники движка, изменения и сборочные файлы.
- `dist/build-info.json` — commit и SHA-256 WAD.
- `web/`, `port/`, `CMakeLists.txt` — исходники браузерного порта.
- `vendor/chocolate-doom/` — клонированный движок с небольшими патчами.
- `assets/freedoom-0.13.0/` — свободный контент.
- `tools/` — локальный SDK и инструменты; глобальные установки не менялись.
- `test-results/` — скриншоты и результат проверки браузера.

## Повторная сборка (Windows)

Нужны Git, Python 3.11+ и доступ к интернету для первоначальной установки.
В PowerShell из корня проекта:

```powershell
./scripts/setup.ps1
./scripts/build.ps1
python scripts/serve.py
```

Инструменты устанавливаются в `tools/`. Конфигурация SDK хранится в
`tools/emsdk/.emscripten`. Сборка выбирает только цель `chocolate-doom`.
Патчи в `scripts/patch_engine.py` применяются повторно безопасно.

Для интеграционной проверки при работающем сервере и установленном Microsoft Edge:

```powershell
python scripts/test_browser.py
```

Проверка запускает реальную игру, проверяет непрерывный поворот камеры при
движении мыши далеко за границы экрана, возврат захвата в полном экране,
сохранение захвата при открытии игрового меню, изменение кадра при движении,
сохраняет игру через F2, перезагружает страницу, сравнивает файл сохранения
байт в байт и загружает его через F3. Это проверка актуального движка и IDBFS.

## Ограничения

- Нужен HTTP/HTTPS. Открытие `index.html` как локального файла не поддерживается.
- В Chromium есть предупреждение об устаревшем `ScriptProcessorNode` внутри
  встроенного порта SDL2. Оно не мешает работе звука; переход на AudioWorklet
  потребует изменения аудиобэкенда SDL.
- Сохранения привязаны к браузеру и origin: `localhost:8000` и `127.0.0.1:8000`
  имеют разные хранилища. Очистка данных сайта удаляет сохранения.
- В приватном режиме или при запрете IndexedDB постоянное хранение может быть
  недоступно. Ошибка показывается под игрой. После F2 дождитесь сообщения
  «Сохранения записаны в браузер» перед закрытием вкладки.
- Сохраняется игра, записанная через F2/меню; непрерывного автосохранения нет.
- Это настольное управление. Экранные кнопки для телефона не добавлены.
- Chocolate Doom сохраняет многие особенности и ограничения оригинального Doom.
  Лимит размера vanilla-сохранений отключён: у Freedoom некоторые уровни его превышают.

## Обновление сайта

Бесплатный публичный репозиторий: https://github.com/dzod992-bit/freedoom-web.
GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает обработку Jekyll.
В репозиторий попадают только готовая игра, лицензии и соответствующие исходники.

```powershell
./scripts/build.ps1
python scripts/publish_github.py
```

Скрипт использует существующий вход Git Credential Manager, не сохраняет токены
в проект и не делает принудительный push. Локальная копия репозитория — `.publish/freedoom-web/`.
Изменения появляются после завершения публикации GitHub Pages.
Сохранения с localhost не переносятся автоматически на публичный адрес.
Проверить публичную версию:

```powershell
python scripts/test_browser.py https://dzod992-bit.github.io/freedoom-web/
```
